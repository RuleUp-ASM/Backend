# 중복 신고 차단 계약

2026-09-18 제품 결정 · QA REP-09

- 최초 신고는 201로 접수하고 대상 차단과 신고 시점 스냅샷을 함께 저장한다.
- 동일 신고자·대상 종류·대상 ID의 재신고는 409 `ALREADY_REPORTED`다. 사유나 발생 화면을 바꿔도 추가 신고를 만들지 않는다.
- 동시에 요청해도 신고 한 건만 남는다. 신고자 행을 잠근 트랜잭션에서 중복 검사부터 적재까지 수행한다.
- 차단 해제는 신고 취소가 아니다. 원본 신고가 남아 있으면 재신고를 허용하지 않는다.
- 다른 사람의 신고와 사용자/챌린지 대상 종류는 각각 독립적이다. 기존 신고와 스냅샷은 삭제하거나 병합하지 않는다.
- 앱은 차단된 대상의 신고 진입점을 숨기고, 우회·재전송으로 409가 오면 “이미 신고한 대상이에요.”를 안내한다.

검증: `ReportBlockContractIT`의 순차 재전송·사유 변경·차단 해제·동시 요청 사례.
